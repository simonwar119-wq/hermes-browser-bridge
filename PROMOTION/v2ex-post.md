**标题**：我做了个 Chrome 侧边栏扩展，能读页面内容并用 AI 自动填写网页表单

---

做了一个 Chrome 扩展，主要解决两个问题：

**1. 一边浏览网页，一边和 AI 聊这个页面的内容**

扩展会读取当前页面的结构化内容（标题、表格转成 Markdown、表单字段），塞进 AI 的上下文里。不用复制粘贴，直接问"帮我总结这个表格"或者"这篇文章的核心观点是什么"，AI 能直接回答。

支持 6 个 AI 提供商，一键切换：DeepSeek / GPT-5 / Claude / Gemini / Grok / Kimi，用自己的 API Key，不经过我的服务器。

**2. 智能自动填表**

我自己经常需要填 App Store 申请、合规表单、各种注册页面，每次都要从头复制粘贴。现在的做法：

- 在扩展的"我的资料"面板里把开发者信息、应用描述、合规答案存一次
- 打开任何表单页面，点一下"扫描并自动填写"
- 扩展扫描所有可见字段，发给 AI 匹配，然后逐个填写

对于 Chrome Web Store 这种受保护页面（内容脚本进不去），可以用 ⌘⇧4 截图，直接在输入框 ⌘V 粘贴，AI 看图帮你分析字段和准备内容。

**其他功能**：截图后内嵌显示在对话里、导航/点击/填表的工具栏按钮、右键菜单快捷总结
