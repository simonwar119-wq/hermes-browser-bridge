Hermes AI Assistant

A Chrome side-panel extension for AI chat plus browser actions. Read the current page, ask mainstream models for help, take screenshots, click elements, fill forms, and connect an optional local Hermes Agent bridge without routing traffic through a developer-owned backend.

Open Repository Privacy Policy README Contributing

Multi-model chat

DeepSeek, OpenAI, Claude, Gemini, Grok, and Kimi with user-supplied API keys.

Browser read/write

Summarize pages, capture screenshots, navigate, click, scroll, and fill forms from the side panel.

Contributor-friendly

Plain HTML, CSS, and JavaScript. No heavy build system required for normal development.

What this project is trying to become

Hermes is evolving into an open-source browser AI operator: something practical enough to use today, transparent enough to review, and simple enough that outside contributors can improve it.

  • Bring your own API key instead of hiding model access behind a hosted service
  • Keep page interaction and user settings local where possible
  • Make permissions and privacy posture reviewable in public
  • Invite contributors to improve browser reliability, UX, and form automation
