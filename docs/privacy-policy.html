Hermes AI Assistant Privacy Policy

Last updated: June 5, 2026

Overview

Hermes AI Assistant is a Chrome extension that provides AI chat about the current webpage, user-invoked browser actions, and optional local Bridge mode for connecting to a local Hermes Agent service.

The extension does not operate its own backend proxy. When AI features are used, requests go directly from the user's browser to the AI provider selected and configured by the user.

Data We Collect

Hermes AI Assistant does not collect, sell, or share user data for the developer's own purposes. We do not run analytics, tracking, advertising, telemetry, or remote logging.

Data Processed by the Extension

  • Current page title and URL
  • Visible page text
  • User-entered chat messages
  • User-provided API keys for supported AI providers
  • User-provided profile and form-fill data stored locally in Chrome
  • User-selected attachments explicitly added to a chat message
  • Screenshots captured by the user

How Data Is Used

  • Answer questions about the current page
  • Summarize, analyze, translate, or explain webpage content
  • Carry out browser actions requested by the user
  • Help fill forms using user-supplied profile information
  • Connect to a local Bridge service if the user enables Bridge mode

AI Providers and Data Transfer

When the user sends a chat request, relevant content may be sent directly to the AI provider chosen by the user. The extension does not forward these requests through any Hermes-controlled server.

Local Storage

The extension stores API keys, selected provider and model, recent conversation history, form-fill profile data, and optional Bridge host configuration locally in Chrome storage on the user's device.

Bridge Mode

If the user enables Bridge mode, the extension connects only to a local service endpoint, such as ws://127.0.0.1:8643.

Permissions

The extension requests only the permissions needed for user-invoked functionality, including reading the current tab, interacting with webpages, storing local settings, and displaying the side panel interface.

What We Do Not Do

  • Sell user data
  • Use user data for advertising
  • Build behavioral profiles
  • Collect browsing history for analytics
  • Send data to a developer-owned backend for storage or analysis

User Control

Users control whether to enter an API key, send a chat request, attach files, capture a screenshot, enable Bridge mode, and save local form-fill profile data.

Contact

If you have questions about this privacy policy, contact the developer through the Chrome Web Store listing or the public project repository.
